# 01 · Datasets

## Local (offline)
80 synthetic arithmetic problems: integer addition / subtraction /
multiplication, operands in [1, 100]. Deterministic ground truth.

## GPU (online via Hugging Face)
- GSM8K (500 examples): `gsm8k/main/test`.
- Hendrycks MATH (200 examples): subset for evaluation.
- 200 additional synthetic problems with operands in [1, 1000].
