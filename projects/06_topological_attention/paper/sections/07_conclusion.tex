\section{Conclusion}
We introduce a fully reproducible pipeline that computes persistent
homology of GPT-2's attention graphs and tests whether truthful and
hallucinated continuations differ topologically. The local pilot is
honestly underpowered ($p=\gptTwoMinPval$, $N=\gptTwoNumPairs$) but
yields an effect-size estimate that motivates a $N\ge 200$-pair GPU
run. Code and curated pairs are released.
